
# Online Job Application Tracker

## Project Description

The Online Job Application Tracker is a web-based application that helps users organize and monitor their job applications in one place.

Users can register, log in, add job applications, update application details, search applications, filter by status, and monitor application statistics.

The administrator can view registered users and monitor all job applications.

## Objectives

- To simplify job application management.
- To maintain application details in one place.
- To track application progress.
- To provide a simple and user-friendly interface.
- To display application statistics.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser Local Storage
- GitHub Pages

## Modules

### 1. User Module
- User registration
- User login
- Password reset
- Add job applications
- View job applications
- Edit application details
- Delete applications
- Search by company or job role
- Filter applications by status
- View dashboard statistics
- Logout

### 2. Admin Module
- Admin login
- View registered users
- View all job applications
- Search applications
- Delete applications
- Logout

## Application Statuses

- Applied
- Interview
- Selected
- Rejected

## Local Storage

The application uses browser Local Storage to store:

- users
- currentUser
- jobs
- adminLoggedIn
