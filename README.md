# Online Job Application Tracker

## Project No.
52

## Problem Statement
Managing multiple job applications manually can be difficult.
The Online Job Application Tracker helps users store, search, and manage their job applications in one place.

## Objective
To develop a simple web-based application that allows users to track their job applications and provides an admin module for managing users and applications.

## Technologies Used
- HTML
- CSS
- JavaScript
- Local Storage

## Modules

### 1. User Module
- User Signup
- User Login
- Add Job Application
- View Applications
- Search Applications
- Delete Applications
- Logout

### 2. Admin Module
- Admin Login
- View Registered Users
- View All Job Applications
- Delete Job Applications
- Logout

## Key Features
- Signup and Login using Local Storage
- JavaScript-based module navigation
- Add and manage job applications
- Search applications by company name
- Admin management of users and applications
- Responsive UI using CSS Grid and Flexbox

## Application Data
User and application data are stored in the browser using Local Storage.
